# Hospital Bed — 3D Modeling & Animation (Autodesk Maya)

A 3D hospital bed modeling project developed in **Autodesk Maya**, from original hand-drawn concept sketches through high- and low-poly scenes and animation demonstrations.

This is a **modeling and presentation exercise**, not a finished game asset or a claim of production-ready optimization. It complements my Unreal Engine gameplay programming projects by showing experience with the 3D asset creation workflow.

## From sketch to model

I drew the original concept sketches by hand before building the model in Maya. They identify planned features such as the mattress, pillow, bed frame, foldable side arms and wheels.

| Front concept sketch | Top concept sketch |
| --- | --- |
| ![Original hand-drawn front concept sketch](Sketches/Front%20Sketch.jpg) | ![Original hand-drawn top concept sketch](Sketches/Top%20Sketch.jpg) |

The resulting model includes side rails, a mattress and pillow, wheels, and a crossed scissor-style support beneath the bed.
